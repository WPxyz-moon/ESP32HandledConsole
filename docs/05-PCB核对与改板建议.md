# 05 · PCB 核对与改板建议

> 核对对象：`Gerber_PCB1_2026-10-27/` 下的 Gerber、钻孔与 `FlyingProbeTesting.json`。  
> **以文件夹内的数据文件为准；`硬件设计参考图.png` 只作辅助参考，不作为连接依据。**  
> 核对日期：2026-11-03。  
> 结论先行：**主控、屏幕、SD、音频、IMU、8 键的连线与参考项目基本一致；但本板没有电池电压采样/电量计，也没有电池过放保护电路。电量显示与低电保护必须外挂 I2C 电量计或改板后才能验收。**

## 2. 模组与电源树

### 2.1 主控

| 项 | 实际值 |
|---|---|
| 模组 | `ESP32-S3-WROOM-1U-N16R8` |
| Flash / PSRAM | 16MB Flash / 8MB Octal PSRAM |
| 天线 | **1U 版本，必须外接 IPEX 2.4G 天线**，模组本身无 PCB 天线 |
| 调试 | 原生 USB Serial/JTAG（GPIO19/20）；SD/LCD 占用 GPIO39–42 后，外部 JTAG 不可用 |
| 串口 | GPIO43/44 被 LCD 占用，**不要再用 UART0 打日志**，统一用 USB Serial/JTAG |

### 2.2 电源拓扑

```text
USB-C 5V ──► D1(SS819WS 肖特基) ──► VSYS_5V ──► SW1 电源开关 ──► EN_ON
      │                                   ▲
      └──► U2 TP4056 ──► VBAT ──► Q1(AO2305) ──┘
                            │       栅极接 USB_5V_IN
                            └──► 电池焊盘 PAD2_VBAT

VSYS_5V ──► U1 SY8088 降压 ──► L1 ──► 3V3 ──► ESP32-S3 / LCD / IMU / 麦克风 / 功放 / SD
```

| 器件 | 位号 | 作用 | 备注 |
|---|---|---|---|
| USB-C | USB1 | 5V 输入、原生 USB | CC1/CC2 各有 5.1k 下拉（R1/R5），识别为受电设备 |
| 肖特基 | D1（SS819WS） | USB 输入防反灌 / 供电路径 | USB_5V_IN → VSYS_5V |
| 充电管理 | U2 TP4056 | 单节锂电线性充电 | 充电电流由 R6 设定；板上有 CHRG/STDBY 指示灯 LED_G1/LED_R2；TEMP 脚接地，无电池温度检测 |
| 自动切换 | Q1（AO2305） | 电池与 VSYS 之间的 P-MOS 开关 | 栅极接 USB_5V_IN：插 USB 时关断电池，拔掉时由 100k 下拉导通 |
| 电源开关 | SW1 | 整机开关，控制 `EN_ON` | 6 脚拨动开关 |
| 降压 | U1 SY8088 | 5V → 3.3V | L1 + R7/R8 反馈 |
| 电量计 | — | **无** | 无分压、无 ADC、无 Fuel Gauge |
| 过放保护 | — | **无** | TP4056 只负责充电，不负责过放/短路保护 |

> 元件型号（D1=SS819WS、Q1=AO2305、U1=SY8088A1AAC 等）来自参考图标注，**连接关系以 `FlyingProbeTesting.json` 为准**；焊接前请与实际 BOM/丝印再核对一次。
>
> **电池必须自带保护板（DW01 + 双 MOS 或同等方案）**，否则整机可能把单节锂电放到 2.5V 以下，造成鼓包/损坏。若电池无保护板，应在电池与主板之间串入保护板，或改板增加保护电路。

### 4.1 屏幕（U8，12 脚 FPC）

| FPC 脚 | 网络 | 说明 |
|---:|---|---|
| 1 | GND | |
| 2 | LEDK | 背光负极，经 Q2 低边开关到地 |
| 3/4 | 3V3 | 背光正极/逻辑供电 |
| 5/6 | GND | |

- 背光：GPIO44 → R19 → Q2 基极；Q2 发射极接地，集电极接 LEDK，属于**NPN 低边 PWM 调光**。`LEDC` 输出高电平点亮。

- 屏幕为 1.69 寸 240×280 ST7789，初始化仍需 `Y offset = 20`。

## 6. 问题清单与处理建议

### P0-1 · 没有电池电压采样 / 电量计

**现象**：VBAT 只连接到 TP4056、Q1 和电池焊盘，没有任何分压电阻到 ADC，也没有 I2C 电量计；TP4056 的 CHRG/STDBY 也只接 LED，没有接到 MCU。  
**影响**：

- 无法显示电量百分比；
- 无法实现“电压 <3.4V 降载 / <3.3V 保存并休眠”的低电保护；
- 无法由固件判断“正在充电 / 已充满 / 未插 USB”；
- 选题申请表/实现方案中的“电量显示、电量误差 <5%”无法验收。

**方案 A（推荐，免改板）**：在现有 I2C 总线上外挂电量计或 ADC。

| 器件 | 地址 | 优点 | 缺点 |
|---|---|---|---|
| MAX17048 | `0x36` | 直接算 SOC，精度好，无需分流电阻 | 封装小，需要转接板 |
| ADS1115 | `0x48` | 模块便宜、接线简单，16 位 ADC | 仍是电压估算，<5% 需校准 |
| INA219/INA226 | `0x40`/`0x41` | 可测电压/电流 | 需要分流电阻，接线更复杂 |

接线：`VBAT → 100k/100k 分压 → ADS1115 A0`（ADS1115 方案），或 `VBAT → MAX17048 VIN`；I2C 并在 U5 的 SCL/SDA（GPIO2/GPIO1）上。分压后加 100nF 滤波。

**方案 B（改板/飞线）**：把 CTRL 从 GPIO8 移到 GPIO47（模组 24 脚，当前悬空），GPIO8 作为 `BAT_ADC`（ADC1_CH7），加分压。  
- 需要切断 U3_12 到 CONTROL 的走线，并把按键飞线到 U3_24；U3_24 没有测试点，焊接难度较高。
- 优点：使用 ADC1，Wi-Fi 工作时也能采样；不牺牲 LED 或 I2C。

**方案 C（不推荐）**：用 GPIO18（LED，ADC2_CH7）做采样，牺牲用户指示灯。  
- GPIO18 属于 ADC2，Wi-Fi 工作时采样可能受限，需要实测；且失去状态灯。

**方案 D（不可接受）**：只按运行时间估算电量。无法满足 <5% 误差和低电保护。

### P0-2 · 电池过放保护缺失

TP4056 只负责充电，不带过放/过流/短路保护。若使用无保护板的裸电芯，整机可能过放到危险电压。  
**处理**：

- 优先采购**自带保护板**的 3.7V 锂电池；或
- 在电池与主板之间加 DW01A + FS8205 保护板；或
- 改板增加保护电路与电池温度检测（TP4056 TEMP 脚）。

### P1-1 · LCD DC/BL 与参考项目相反

- 实际：`LCD_DC=GPIO43`，`LCD_BL=GPIO44`。
- 参考：`LCD_DC=GPIO44`，`LCD_BL=GPIO43`。
- 处理：只改固件 `bsp_board.h`，**不需要改硬件**。点屏前先确认这两个宏，否则表现为“背光常亮/不受控、屏幕无显示或花屏”。

### P1-2 · 1U 模组必须外接天线

`ESP32-S3-WROOM-1U` 没有 PCB 天线，必须接 IPEX 1 代 2.4G FPC 天线。  
**处理**：装配时接好天线，天线远离电池、金属外壳和屏幕排线；有条件做一次 Wi-Fi RSSI/BLE 距离对比。

### P1-3 · 充电状态没有接到 MCU

TP4056 的 `CHRG`/`STDBY` 只驱动 LED_G1/LED_R2，没有接到任何 GPIO。固件无法知道“正在充电 / 已充满 / 未插 USB”。  
**处理**：

- 最简：不显示充电状态，只显示电量（仍需先解决 P0-1）；充电状态看板上 LED。
- 若要软件显示：从 CHRG/STDBY 节点取信号，但该节点被 LED 上拉到 USB 5V，**不能直接接 3.3V GPIO**，需要分压/电平转换或加三极管；或者外挂 I2C 电流/电量计（如 INA219）判断充电电流。
- 另一个低成本办法：用电阻分压 `USB_5V_IN` 到空闲 GPIO，只判断“是否插了 USB”，不判断是否在充电。

### P2-1 · SD 卡检测脚未接

J1 的 CD（脚 1/8）悬空。  
**处理**：固件启动时尝试挂载，失败则显示“请插入 SD 卡”；设置页提供“重新扫描”。不要依赖热插拔中断。

### P2-2 · IMU 中断脚未接

U5 的 INT1/INT2 悬空。  
**处理**：IMU 任务定时轮询（50–100Hz），软件做摇晃/翻转判定；不要在低功耗设计里承诺“运动唤醒”。

### P3-1 · AHT20 未设计

PCB 上只有 LSM6DS3TR-C，没有 AHT20。  
**处理**：AHT20 保持“可选外挂”，通过 I2C 扩展；不纳入 MVP 验收。

### P3-2 · GPIO47/48 没有测试点

U3_24/25 为单脚网络，没有引出测试点。  
**处理**：如果要做“CTRL 移到 GPIO47”的改板，需要直接焊模组引脚，建议用 0.1mm 漆包线 + 放大镜/显微镜，先在其他板子上练手。

## 8. 上电与点屏检查顺序

1. **不上电**：目视检查 QFN/QFP 连锡、FPC 座异物、电池极性；万用表测 3V3 对地、VBAT 对地是否短路。
2. **只插 USB、不接电池**：测 `USB_5V_IN`、`VSYS_5V`、`3V3`；确认 SY8088 输出 3.3V±5%。
3. **接电池**：确认 D1/Q1 自动切换（插拔 USB 时 VSYS 不掉电）；拨动 SW1，测 `EN_ON` 与 3V3。
4. **烧录**：`esptool.py flash_id` 确认 16MB；读 MAC；跑 PSRAM 测试（确认 8MB Octal 可用）。
5. **点屏**：用 `LCD_DC=43`、`LCD_BL=44` 初始化；显示三色/彩条；PWM 调背光。
6. **按键**：8 键逐个打印；确认低有效、内部上拉、消抖 10–20ms。
7. **SD**：SPI3 38/40/39/41 挂载 FAT32；拔卡后重试不崩溃。
8. **I2C**：扫描到 `0x6A`；读 IMU WHO_AM_I。
9. **音频**：I2S0 录音回环、I2S1 播放 1kHz 正弦；确认无爆音。
10. **无线**：接 IPEX 天线，测 Wi-Fi RSSI 与 BLE 连接距离。

## 10. 验收前必须回答的三个问题

1. **电量怎么来？** 没有电量计就没有电量百分比，也没有低电保护。答辩前必须补装并调通。
2. **电池有没有保护板？** 没有就换电池或加保护板，不能用裸电芯直接接主板。
3. **天线装了吗？** 1U 模组不接天线，Wi-Fi/BLE 距离会明显不达标。
