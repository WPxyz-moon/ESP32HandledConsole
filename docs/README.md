## 一句话架构

**一颗 ESP32-S3 + 三套独立固件**：`factory` 主系统负责菜单、设置、BLE HID、Wi-Fi 音频与电源管理；`ota_0` 游戏系统运行 Retro-Go / nofrendo NES 模拟器；`ota_1` AI 系统运行文本对话、语音对话与图形化 AI 宠物。三套固件通过 `otadata` 切换，切换时重启并清空 RAM，从机制上避免长期运行后的内存碎片与 OOM。

```text
                    ┌──────────────────────────────┐
                    │        ESP32-S3 (N16R8)      │
                    │  8MB PSRAM / 16MB Flash      │
                    │  Wi-Fi 2.4G / BLE 5.0        │
                    └──────────────┬───────────────┘
                                   │
          ┌────────────────────────┼────────────────────────┐
          │                        │                        │
   ┌──────▼──────┐          ┌──────▼──────┐          ┌──────▼──────┐
   │  factory    │          │    ota_0    │          │    ota_1    │
   │  主系统     │          │  游戏系统   │          │  AI 系统    │
   │ 菜单/设置   │          │ Retro-Go    │          │ 文本/语音   │
   │ BLE/Wi-Fi   │          │ NES 模拟器  │          │ AI 宠物     │
   └─────────────┘          └─────────────┘          └─────────────┘
```

## 硬件前提（开工前先确认）

本方案按 **ESP32-S3-WROOM-1U-N16R8（8MB Octal PSRAM + 16MB Flash）** 设计。项目内已有实际 PCB：`Gerber_PCB1_2026-10-27/`；**引脚与连接以该文件夹的数据文件（Gerber / `FlyingProbeTesting.json`）为准**，`硬件设计参考图.png` 只作辅助参考。完整核对见 [05-PCB核对与改板建议.md](05-PCB核对与改板建议.md)。

- [x] 模组：`ESP32-S3-WROOM-1U-N16R8`，16MB Flash / 8MB Octal PSRAM
- [x] 屏幕：ST7789 240×280 SPI（1.69 寸）
- [x] 音频：MSM261 数字麦克风 + MAX98357 数字功放
- [x] 传感器：LSM6DS3TR-C 六轴 IMU
- [x] 存储：microSD（SPI3）
- [x] 按键：8 键，含独立 CTRL（GPIO8）
- [ ] 电池：**必须使用自带保护板的 3.7V 锂电池**（PCB 只有 TP4056 充电，无过放保护）
- [ ] 电量采样：**当前 PCB 无 BAT_ADC / 电量计**，需外挂 I2C 电量计（MAX17048/ADS1115）或改板
- [ ] 充电状态：**TP4056 的 CHRG/STDBY 只接 LED，没有接到 MCU**；软件要显示充电状态需额外引出/电平转换
- [ ] 天线：1U 模组必须外接 IPEX 2.4G 天线

> **重要**：当前 PCB 没有电池电压采样。未补装电量计前，“电量百分比、低电保护、电量误差 <5%”无法验收。处理方案见 [05 §6](05-PCB核对与改板建议.md#p0-1--没有电池电压采样--电量计)。
>
> 如果手上是经典 ESP32（非 S3）或没有 8MB PSRAM，本方案的“三固件 + LVGL + NES + 语音”需要降级：优先保留单固件主系统 + NES，AI 与三固件作为选做。具体裁剪见 [03-项目实现计划.md](03-项目实现计划.md)。

## 方案边界

**要做**：LVGL 图形界面、NES 模拟器、AI 文本助手、图形化 AI 宠物（按键/重力/语音）、Wi-Fi 音频、BLE 键盘/手柄、三固件切换、电源管理、数字音频系统、Ctrl 键与键盘映射。

**不做**（按《手柄实现方案》）：天气、占卜、频谱分析仪；参考项目中的音乐/视频播放器也不在本次范围。
