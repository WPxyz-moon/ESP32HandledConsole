## 一句话架构

**一颗 ESP32-S3 + 三套独立固件**：`factory` 主系统负责菜单、设置、BLE HID、Wi-Fi 音频与电源管理；`ota_0` 游戏系统运行 Retro-Go / nofrendo NES 模拟器；`ota_1` AI 系统运行文本对话、语音对话与图形化 AI 宠物。三套固件通过 `otadata` 切换，切换时重启并清空 RAM，从机制上避免长期运行后的内存碎片与 OOM。

```text
                    ┌──────────────────────────────┐
                    │        ESP32-S3 (N16R8)      │
                    │  8MB PSRAM / 16MB Flash      │
                    │  Wi-Fi 2.4G / BLE 5.0        │
                    └──────────────┬───────────────┘
                                   │
          ┌────────────────────────┼────────────────────────┐
          │                        │                        │
   ┌──────▼──────┐          ┌──────▼──────┐          ┌──────▼──────┐
   │  factory    │          │    ota_0    │          │    ota_1    │
   │  主系统     │          │  游戏系统   │          │  AI 系统    │
   │ 菜单/设置   │          │ Retro-Go    │          │ 文本/语音   │
   │ BLE/Wi-Fi   │          │ NES 模拟器  │          │ AI 宠物     │
   └─────────────┘          └─────────────┘          └─────────────┘
```

## 硬件前提（开工前先确认）

本方案按 **ESP32-S3 + 8MB Octal PSRAM + 16MB Flash** 设计（常见模组：`ESP32-S3-WROOM-1-N16R8`）。请先核对：

- [ ] 模组型号是否为 ESP32-S3，且带 8MB PSRAM / 16MB Flash
- [ ] 屏幕是否为 ST7789 240×280 SPI 彩屏
- [ ] 是否有 MSM261 数字麦克风与 MAX98357 数字功放
- [ ] 是否有 LSM6DS3TR-C 六轴 IMU
- [ ] 是否有 microSD 卡槽
- [ ] 是否有锂电池、充电/保护电路与电池电压分压采样

> 如果手上是经典 ESP32（非 S3）或没有 8MB PSRAM，本方案的“三固件 + LVGL + NES + 语音”需要降级：优先保留单固件主系统 + NES，AI 与双固件作为选做。具体裁剪见 [03-项目实现计划.md](03-项目实现计划.md)。

## 方案边界

**要做**：LVGL 图形界面、NES 模拟器、AI 文本助手、图形化 AI 宠物（按键/重力/语音）、Wi-Fi 音频、BLE 键盘/手柄、双固件切换、电源管理、数字音频系统、Ctrl 键与键盘映射。

**不做**（按《手柄实现方案》）：天气、占卜、频谱分析仪；参考项目中的音乐/视频播放器也不在本次范围。
