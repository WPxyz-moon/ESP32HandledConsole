# ESP32 Handled Console

基于 ESP32-S3 的多模态 AI 游戏掌机项目：LVGL 图形界面 + NES 游戏 + AI 文本/语音助手 + 图形化 AI 宠物 + BLE HID + Wi-Fi 音频 + 双固件切换。
